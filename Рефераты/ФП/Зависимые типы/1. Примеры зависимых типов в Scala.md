Система типов в последней версии Scala 3 предлагает мощный набор инструментов для выражения зависимых типов (когда тип зависит от конкретного терма/значения или другого типа).

Ниже перечислены основные способы кодирования зависимых типов в Scala 3, от классических до новейших возможностей языка:

## 1. Типы, зависимые от пути (Path-Dependent Types)

Это классический для Scala механизм, при котором вложенный тип жестко привязан к конкретному экземпляру внешнего объекта (пути). [1, 2]

```scala
trait Document:
  type Node // абстрактный тип внутри экземпляра
  def root: Node

val docA = new Document { type Node = String; def root = "A" }
val docB = new Document { type Node = Int;    def root = 42 }

// Тип docA.Node и тип docB.Node для компилятора абсолютно разные!
val nodeA: docA.Node = docA.root
// val nodeError: docA.Node = docB.root // Ошибка компиляции!
```

## 2. Зависимые типы методов (Dependent Method Types)

Метод может возвращать тип, который зависит от типа переданного в него аргумента (значения). Для этого возвращаемый тип ссылается на имя параметра. [2, 3]

```scala
trait Key { type Value }
object Name extends Key { type Value = String }
object Age  extends Key { type Value = Int }

def lookup(key: Key): key.Value = ??? 

val name: String = lookup(Name) // Компилятор знает, что результат String
val age: Int     = lookup(Age)  // Компилятор знает, что результат Int
```

## 3. Зависимые типы функций (Dependent Function Types) — _Новое в Scala 3_

В Scala 2 зависимыми могли быть только методы. В Scala 3 появились полноценные зависимые функции. Теперь такие функции можно сохранять в переменные и передавать как аргументы высшего порядка. [3, 4]

```scala
// Определение типа зависимой функции
type LookupFunc = (k: Key) => k.Value

// Создание значения такой функции
val myLookup: LookupFunc = (k: Key) => ???
```

Под капотом этот синтаксис разворачивается в стандартный `Function1` с уточнением (refinement) метода `apply`. [5, 6]

## 4. Типы соответствия (Match Types) — _Новое в Scala 3_

Позволяют вычислять тип на этапе компиляции, сопоставляя его по образцу с другими типами. В связке с методами они образуют мощный механизм зависимой типизации: [7, 8, 9]

```scala
type ElementAt[X] = X match
  case String => Char
  case Box[t] => t

// Зависимый метод, использующий Match Type
def getFirst[T](x: T): ElementAt[T] = x match
  case s: String => s.charAt(0)
  case b: Box[t] => b.value
```

## 5. Литеральные типы и compile-time операции (Literal Types & `scala.compiletime`)

В Scala 3 типом может выступать конкретное литеральное значение (например, `42` или `"hello"`), а пакет `scala.compiletime.ops` позволяет вычислять значения (например, размеры векторов) на уровне типов. [10]

```scala
import scala.compiletime.ops.int.*

// Тип списка, зависящий от его длины (Sized List)
enum SizedList[+A, L <: Int]:
  case Nil extends SizedList[Nothing, 0]
  case Cons[A, N <: Int](head: A, tail: SizedList[A, N]) extends SizedList[A, N + 1]

val list: SizedList[String, 2] = SizedList.Cons("a", SizedList.Cons("b", SizedList.Nil))
```

## 6. Шаблон Aux (Aux Pattern)

Исторический паттерн из Scala 2 (популяризированный библиотекой `shapeless`), который до сих пор актуален в Scala 3 для обхода ограничений при использовании зависимых типов в тайпклассах. Он переводит зависимый путь-тип во внешний параметр типа. [2, 11]

```scala
trait Evaluator[In]:
  type Out
  def eval(in: In): Out

object Evaluator:
  // Магия паттерна Aux:
  type Aux[In, Out0] = Evaluator[In] { type Out = Out0 }
```

## Сравнительная таблица способов

|Способ кодирования|От чего зависит тип?|Когда использовать?|
|---|---|---|
|Path-Dependent Types|От конкретного объекта (`obj.Type`)|Архитектура плагинов, модули, изоляция контекстов.|
|Dependent Methods/Functions|От значения аргумента (`arg.Type`)|Безопасные ключ-значение хранилища, динамические схемы.|
|Match Types|От структуры другого типа (`T match ...`)|Вывод типов в обобщенных библиотеках без бойлерплейта.|
|Compile-time Ops & Literals|От инкрементов/значений на уровне типов|Валидация матриц, размеров векторов, протоколов.|
